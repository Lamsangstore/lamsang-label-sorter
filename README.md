# Lamsang Label Sorter

เว็บแอปเรียงใบปะหน้าพัสดุของ Lamsang Store ตามรุ่น → สี → ไซส์ รองรับ TikTok Shop, Shopee (Seller Centre) และ Lamsangstore/Page365 แยกไฟล์ตามขนส่ง (J&T / Flash) และสรุปยอดหยิบของ

- ไฟล์เดียว `index.html` ใช้ pdf.js + pdf-lib จาก cdnjs
- ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มีการอัปโหลดไฟล์ออกนอกเครื่อง
- โฮสต์บน GitHub Pages โดเมนตั้งในไฟล์ `CNAME`

ตรรกะการเรียงเหมือนสกิล `sort-shipping-labels` — ถ้าแก้กติกา (รุ่น/สีใหม่) ต้องแก้ทั้งสองที่
